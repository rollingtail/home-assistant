# Tailscale Home Assistant Add-on

This repository contains the Tailscale Home Assistant add-on, featuring zero config VPN for building secure networks.

## Installation

You can add this repository to your Home Assistant instance by clicking the button below:

[![Open your Home Assistant instance and show the add app repository dialog with a specific repository URL pre-filled.](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Frollingtil%2Fhome-assistant)

Alternatively, you can manually add the repository by following these steps:

1. Copy the Repository URL: `https://github.com/rollingtil/home-assistant`
2. Go to **Settings** > **Add-ons** > **Add-on Store** in your Home Assistant instance.
3. Click the three dots (overflow menu) in the top-right corner and select **Repositories**.
4. Paste the URL into the input field and click **Add**.
5. Close the dialog, and after the store refreshes, search for **Tailscale** and click **Install**.
